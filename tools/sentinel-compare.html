Sentinel-2 vs Mapbox Satellite — is free imagery good enough for this game?

Both panels are 2×2 native 256px tiles at the same z/x/y, drawn 1:1 with no upscaling, so what you see is each source's true resolution. Sentinel-2's colour bands are 10 m/px and EOX serves them to z14; past that it is upscaling, not resolving. Mapbox is sub-metre in most populated places. The question this tool answers is not "which is sharper" (Mapbox, obviously) but "at the zooms this game actually uses, can you still tell the city?"

Why the zoom ceiling is the whole argument. The game frames a round 25 miles wide. On a 1900px-wide window that is about 21 m/px, so at the opening view Sentinel-2 is already finer than the screen shows — it would look identical. It stays honest for roughly two more zoom levels and then goes to mush, and zooming in is exactly how you settle between two candidate cities. So the realistic shape is a hybrid: Sentinel for the default framing (which is most of the round), Mapbox only once someone zooms past its ceiling. Mapbox bills when the map object is created, so a hybrid only saves money if the Mapbox map isn't constructed until it's needed.

Mapbox tiles here come from the raw tile endpoint, which is the expensive billing path — the same caveat as imagery-compare.html. Fine for a handful of comparisons, never for production. Loading this page a few dozen times costs cents; leaving it open on a loop does not.
